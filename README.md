# 星之祈願：守護小隊｜重製版星願旅程

四場景十二關的獨立手機橫向守塔遊戲。使用原有核准素材，Phaser 4.2.1 負責場景、素材載入與互動，獨立模型負責波次、移動、索敵、經濟與命中。

## 本次完成
- 四章各三關：花語森林、月溪古道、星霜遺跡、祈願聖域；每關獨立路線與 8～15 波編排。
- 單／雙入口、快敵、護盾、厚血巨像與章末頭目；保留第一關原本路線與八波。
- 章節選關、關卡準備、下一關與重玩；通關依序開放後續關卡。
- 六種守護塔資料與圖鑑：弓箭初始開放，其餘依旅程解鎖；通關第九關後可完成星隕試煉，永久取得星隕。
- 前五塔在 Lv.2 選分支、Lv.5 最終進化；星隕只有 Lv.1／Lv.2 兩型態、無分支。
- 冰霜減速／凍結、雷電連鎖、星輝持續鎖定增傷、星隕延遲範圍落點。
- 隨時建造、升級、拆除，最多同時 6 座。
- 命中、拋物線火球、升級與金幣回饋；落地陰影、環境飄葉。
- 橫向滿版、安全區、暫停、1×／2×、預設自動接波。
- 圖鑑有實際名稱與可點選的能力資料。
- 手機直向暫停，回到橫向後手動繼續。
- 勝敗、重玩、返回選關／主畫面；音效預設關閉。

## 第三階段：試煉、祝福與分裂敵人

**星隕試煉**：通關第九關後開放，是獨立三波教學，不占十二關星數。450 起始金幣、一座 Lv.1 固定借用祭壇（不可拆除／升級、不占支援名額），可另建最多兩座冰霜塔、最高 Lv.2。必須守住三波並累積至少六次「隕石命中正被減速／凍結的敵人」。奔行幻影速度 180，未受控制時能移出落點；不是提高血量來要求堆輸出。成功永久保存 trialWon，失敗不失去既有資格；星隕最終型態仍需累積 30 星。試煉不提供祝福、不發挑戰星，也不消耗星數。

**本局祝福**：一般關卡第 3、6 波清空後，各提供一次三選一，可略過。模型與 UI 都會暫停推進，不能誤開下一波；必須選擇或明確略過。最多兩次選擇，重玩／換關清空，不寫進永久進度。提供內容會依塔資格、目前生命及已選層數調整。

## 手機畫質與森林遺跡介面

`dist/viewport.js` 以實際 drawing buffer 像素處理高密度螢幕；Phaser 4.2.1 不會採用舊的 `GameConfig.resolution` 欄位。原本 DPR 3、844×390 的裝置仍只建立 844×390 畫布；現在會建立 1688×780 畫布，CSS 尺寸仍為 844×390。密度上限 2，額外高密度渲染約以 300 萬像素為預算；原生 CSS 面積更大的畫面不向下取樣。場景以 CSS 座標排版、相機放大至實體像素，原生 Phaser 輸入與 DOM 平台區同步。這不會增加原始森林圖片（887×443）的細節，也未修改塔圖；精簡特效只減少效果，不改渲染密度。

戰鬥頂列以波次數字按鈕開啟敵人預告與自動接波設定；備戰顯示開始下一波，戰鬥中顯示暫停／繼續。暫停選單分為本場狀態、兩欄手札入口、次要離場操作，固定保留繼續守護；音效與特效移至設定。對話框、建塔列與 HUD 使用森林綠、象牙白和暖金材質。

空平台加入缺角、裂紋、礦物斑點、青苔、草與接地陰影；細節由固定種子產生，戰場重繪不會閃動。點選顯示星紋，選塔時保留原圖半透明預覽；確認後隱藏空底座，由原有塔圖呈現完整底座，附 600ms 星光修復回饋（精簡／減少動態為 180ms），建造立即生效，暫停時回饋仍會結束。取消不扣金幣，拆除恢復風化遺跡。

`python3 tests/browser-mobile-polish.test.py` 驗證 DPR 1／2／3 的真實畫布尺寸、844×390／667×375／932×430／1440×900 的介面、原生 Phaser 觸控與 DOM 對齊、選單、波次設定、預覽取消、暫停建造活化和拆除。截圖及渲染報告預設寫至 `/tmp/star-wish-mobile-polish`，可用 `POLISH_ARTIFACTS` 更改。這是 Chromium 模擬；實體手機的發熱、耗電、幀率和 Safari 仍須實機確認。

## 星願補給所（趣味模擬）

主頁的次要入口提供「星光小袋、祈願寶箱、守護者典藏箱」三款禮包；點選後確認模擬兌換，播放可跳過的開箱並收藏紀念徽章。所有畫面固定標示「趣味模擬，無實際付款，不會收取費用」。按讚、加油與請喝飲料都只是遊戲內說法，不要求任何實際操作，沒有金流、贊助連結、廣告、訊息或個人資料表單。
