# 星之祈願：守護小隊｜重製試玩 01

一關獨立的手機橫向守塔遊戲品質樣板。使用原有核准素材，Phaser 4.2.1 負責場景、素材載入與互動，獨立模型負責波次、移動、索敵、經濟與命中。

## 本次完成
- 花語森林一關、8 波、4 種敵人。
- 弓箭與火焰塔；連射／狙擊、爆炎／灼燒；5 級最終外觀。
- 隨時建造、升級、拆除，最多同時 6 座。
- 命中、拋物線火球、升級與金幣回饋；落地陰影、環境飄葉。
- 橫向滿版、安全區、暫停、1×／2×、預設自動接波。
- 圖鑑有實際名稱與可點選的能力資料。
- 手機直向暫停，回到橫向後手動繼續。
- 勝敗、重玩、返回主畫面；音效預設關閉。

## 驗證
`node tests/model.test.cjs`

以瀏覽器內嵌視窗驗證 844×390、667×375 與 390×844 直橫向切換；並驗證建造、扣款、分支、暫停及第一波。沒有宣稱使用實體 iPhone 完整通關。完整八波勝敗流程由模型測試驗證。

此樣板不讀寫正式版存檔，不是正式版覆蓋部署。數值為試玩基線，完整平衡調整仍待後續。

## Codex 接手
先讀 AGENTS.md 與 HANDOFF.md。`npm run dev` 啟動後開啟 http://localhost:8000 。需 Python 3 與 Node.js 20+，無需 npm install；Phaser 已固定在 vendor。`npm test`、`npm run check` 執行驗證。本分支不含部署工作流程，不應推送 main。
